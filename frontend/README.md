# Sistem Absensi - Frontend

Folder ini berisi kode **React.js** dengan desain **Modern Glassmorphism**.

## 🎨 Tech Stack
*   **React** (TypeScript)
*   **TailwindCSS** (Styling & Glass Effects)
*   **Chart.js** (Dashboard Analytics)
*   **Lucide React** (Modern Icons)
*   **Axios** (API Connection)

## ⚠️ Cara Menjalankan
Disarankan untuk menjalankan aplikasi dari **ROOT FOLDER** (`Sistem_Absensi`) agar Backend juga ikut jalan.

Buka terminal di folder `Sistem_Absensi` dan ketik:
```bash
npm start
```

## Struktur
*   `src/` - Kode utama React (Components, Pages).
*   `public/` - Aset statis (Index.html).

Untuk dokumentasi lengkap, silakan baca file **[README.md](../README.md)** di folder utama.
